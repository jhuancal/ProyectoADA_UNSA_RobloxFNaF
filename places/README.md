# 📦 Places de Roblox (.rbxl)

Esta carpeta está destinada a guardar las copias de seguridad del archivo completo de Roblox Studio (`.rbxl`).

### ¿Cómo guardar el proyecto aquí?
1. En **Roblox Studio**, ve a:
   `Archivo (File) > Guardar en archivo como... (Save to file as...)`
2. Selecciona esta carpeta `places/` y guarda el archivo con el nombre:
   `ProyectoADA_UNSA_FNaF.rbxl`

> [!NOTE]
> Al estar en esta carpeta, cualquier miembro del equipo puede clonar el repositorio de Git, hacer doble clic en el `.rbxl` y abrir la versión completa del juego directamente en Roblox Studio.
