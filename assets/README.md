# 🎨 Modelos y Recursos Modulares (.rbxm / .rbxmx)

Esta carpeta almacena los modelos 3D y componentes visuales exportados de forma modular desde Roblox Studio.

### Modelos principales del proyecto:
* `AnimatronicModels.rbxm`: Carpeta con los modelos 3D de Bonnie, Chica, Foxy y el Escenario.
* `MapBlockoutV2.rbxm`: Mapa físico 3D con habitaciones (`Rooms`), waypoints (`MovementPoints`), cámaras (`CameraPoints`) y decorados (`EnhancedVisuals`).

### ¿Cómo exportar un modelo desde Roblox Studio?
1. En el **Explorador** de Roblox Studio, haz clic derecho sobre el modelo o carpeta (ej. `Workspace.AnimatronicModels`).
2. Selecciona **"Guardar en archivo..." (Save to file...)**.
3. Guárdalo dentro de esta carpeta como archivo `.rbxm` (binario) o `.rbxmx` (XML).
